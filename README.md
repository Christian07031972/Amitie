# Amitié Web

Vidriera estática inicial de Amitié.

## Archivos

- `index.html`: estructura y textos de la página.
- `styles.css`: diseño, colores y adaptación a celulares.
- `script.js`: menú móvil y animaciones de entrada.

## Publicación en GitHub Pages

1. Crear un repositorio nuevo en GitHub.
2. Subir los cuatro archivos de esta carpeta a la raíz del repositorio.
3. En GitHub, abrir **Settings → Pages**.
4. En **Build and deployment**, seleccionar **Deploy from a branch**.
5. Elegir la rama `main`, carpeta `/ (root)` y guardar.

La página no usa base de datos ni requiere instalación.
